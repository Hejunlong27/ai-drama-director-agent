# 两条铁律 · 量化落地表（Iron Rules)

> 本文件是「短剧AI导演Agent」全流程的强制约束基准，供 M1–M9 各模块 prompt 与验收清单共同引用。
> 铁律不可被任何模块改写/放宽；出现冲突判定一律以本文件为准。

---

## 铁律① 景别铁律

> **人物镜头避免远景；以中景、近景、特写、大特写为主；交代环境时使用空镜远景（无人物或人物极小）。**

### 1.1 景别专断表

| 景别 | 角度 | 人物镜头是否允许 | 允许用途 | 判据（可否通过） |
|---|----|:---:|---|---|
| 大特写 | 锁定屏幕/手/眼/物件 | ✅ 允许 | 情绪爆点、信息细节、爽点/泪点的"钉死" | PASS |
| 特写 | 面部/局部 | ✅ 允许 | 台词情绪、心理动作、目光 | PASS |
| 中近景 | 肩到腰 | ✅ 允许 | 双人对话、心理张力 | PASS |
| 中景 | 腰到膝 | ✅ 允许 | 人物互动/动作 | PASS |
| 近景 | 胸到肩 | ✅ 允许 | 主体反应、对白主位 | PASS |
| 过肩 | 单人/双人 | ✅ 允许 | 对峙、权力交换 | PASS |
| 全景 | 全身 | ⚠️ 仅限无人物或人物极小 | 交代环境的空镜；不允许纯人物行动主轴 | 人物显著→FAIL |
| 远景 | 大环境 | ⚠️ 仅限无人物或人物极小 | 转场定场空镜；不允许人物主体 | 人物显著→FAIL |

**硬判据（审片门禁）**：
- 🚫 人物镜头出现「远景/全景且人物是视觉主体」→ FAIL，回调 M3 重做该镜头。
- ✅ 交代环境（场口/转场/时空交代）→ 空镜远景，人物不出现或占比极小（<10% 画面）。
- ✅ 人物戏 → 必须落在中景/中近/近景/特写/大特写/过肩。

### 1.2 机位高度 ≠ 景别豁免

机位高度用于表达权力关系（仰拍=权高/有力，俯拍=权低/受制），但**机位高度不改变景别规则**：
- 允许：仰拍特写/俯拍特写、仰拍近景/俯拍近景……
- 禁止：为了"表现权力"而把人物放到满脸对不上焦的远景里。权力冲突用景别+机位+运镜同时作用于中近特写来表达。

### 1.3 对 M3/M4/M5/M6 的注入点

- M3 分镜：镜号下"景别/角度"栏强制按专断表取值；新增镜必须填写 allowed 景别。
- M4 音效灯光：不因"镜头够远就不用做表情/灯光细节"，人物镜头仍要逐镜做面光与微表情。
- M5 转场：环境桥接用空镜远景；人物转场用特写落点。
- M6 H3：detailed_description 内每个 `[Shot k]` 的景别词行文必须落在合法景别集。

## 铁律①b 单集全局 subject_definitions（复用锚点）

> **人物和场景，在 `subject_definitions:` 中都必须指定为 `<Subject N>`；同一集剧本锁定同一套 `subject_definitions`，供整集各视频段复用。**

### 2b.1 全局锁定规则
- 单集开头先产出一份**全局 subject_definitions**（按该集出场顺序给所有人/场景编 `<Subject 1..N>` 与对应 `<Picture N>`）。
- 该集所有 H3 段一律引用这份全局定义，**不在段内各自另起一套**；每段 `subject_definitions` 只列出"本段实际出现的 subject" + 引注"沿用本集全局套（见单集头部全集定义）"。
- 复用目的：生成视频时跨段保持人物/场景一致性，段与段可直接复用同一批参考图锁定。

### 2b.2 必达约束（每段校验）
| 项 | 要求 | FAIL |
|---|---|---|
| 人物必须指定 Subject | 每次出现的人物都必须在 `subject_definitions` 以 `<Subject N> is …` 定义 | 人物出现但未定义 → FAIL |
| 场景必须指定 Subject | 每次出场的场景都必须在 `subject_definitions` 以 `<Subject M> is …`/`<Picture M> 定义场景` 定义 | 场景出现但未定义 → FAIL |
| 全局唯一 | 同一角色在整个单集只能有一个 `<Subject N>`（全局 ID 跨段一致，不重编） | 同角重编 → FAIL |
| 逐字外观 | 外观描述跨段逐字一致（人物/场景），锁定五官/发型/服装/布局/光线 | 描述漂移 → FAIL |

### 2b.3 注入点
- M3 分镜：编列"本集全局 subject 清单"（人物 Subject + 场景 Subject）。
- M6/M9 H3：段内 subject_definitions 列本段 subject 并引注全局套。
- M7 质检：校验"出现即定义""全局唯一""外观跨段一致"。
- 与现场示例对齐：见 `EP001_H3_Ref2VA_合并稿.md` 开头"全局参考｜subject_definitions 汇总"。

## 铁律② 溯源约束

> **模块的输出必须严格基于原始剧本和前面所有模块已确立的框架，不得超出范围创作任何新内容；所有补充必须能从剧本原文或前序输出中合理推导。**

### 2.1 溯源规则

所有"制造新内容"的模块（M1–M9 中产出描述/镜头/音效/灯光的模块）必须满足：

| 类型 | 是否允许 | 要求 |
|---|---|---|
| 直接引用台词 | ✅ | 100% 逐字复制剧本 `script.json` 的 `flow[].line`，含省略号/破折号/叹号/问号，一字不改 |
| 复用前序模块字段 | ✅ | 必须指认来源字段（如"引自 M3 分镜镜号 03 的景别"） |
| 场景/道具延续 | ✅ 顺推 | 仅限同场景内前序已确立的元素（桌椅、凭证盒、打印机、泡面碗等原剧本/前序明示过） |
| 角色外观延续 | ✅ 顺推 | 仅限前序/资产锚点已确立的外观、服装昼夜换装等脚本设定 |
| 情绪自然延伸 | ✅ 顺推 | 由台词语气/动作可明确推导的微表情、呼吸、眼神 |
| 引入新人物/新场景/新道具 | 🚫 | 不在剧本/前序中 → 禁止；导致 FAIL |
| 改写/润色/补充台词 | 🚫 | 禁止；台词只可逐字引用 + 标注 delivery 语气（语气词不改动台词字面） |
| 脑补不存在的剧情事实 | 🚫 | 如"沈知远是幕后主使"之类剧本未明示的定性 → 禁止 |

### 2.2 溯源标注要求

对任何非直引的衍生内容，在模块输出中标注推导链：
`<字段值>（源于 <剧本场节点>/<M前置模块号.field>）`
- 例：`茶水间午后暖光透百叶窗（源于 script.json S04 lighting="白天暖光"）`
- 例：`林晚星海军蓝素衬衫（源于资产锚点 + script.json S01/S02 深夜设定）`

## 台词权威来源

- 唯一权威：`{EP}\-script.json`（`episodes[].scenes[].flow[].line`）。
- 禁止以叙述性剧本 md / 个人记忆 / 现场合并稿台词为准——一切台词逐字比对 `script.json`。
- 角色 ID 双向映射（现场）：
  - `script.json` 角色 ID：`C01` 林晚星、`C02` 顾季、`C03` 乔一、`C04` 沈知远、`C05` 唐絮。
  - 现场资产编号：林晚星=1、顾季=2、乔一=3、沈知远=4、周恒=5、唐絮=6。
  - H3 参考图 `<Picture N>` 编号以各段内实际排列为准（见 h3_official.md）。

## 爆款节奏基线（经验阈值，可配置）

- 前 3 秒钩子：第 1 镜口或首 3s 内必须出现信息钩子/情绪钩子。
- 每 15–20s 一个爽点/小爆点；单集 60–90s 需 2–4 个节奏峰。
- 爽点/泪点的镜头必须强化（大特写 + 短节奏 + 音效聚焦）。
- 标注：此为经验基线，非官方硬标准；作为 M2/M5/M7 的默认配置基线。
